# ARP Spoofing Practice (without proxy)

##Overview 
This project is a hands-on project of ARP Spoofing ( Man-in-the-Middle) **without configuring a proxy on the target phone**.
Traffic is redirected to Burp Suite (invisible Proxy) using ip tables.

##Objectives

-Perform ARP Spoofing without proxy.
-Redirect traffic using iptables.
-Use Burp Suite invisible Proxy.
-Intercept HTTPS traffice (with CA Certificate).

##Tools Used

-Kali Lunix
-arpspoofing(dsniff)
-Burp Suite (invisible proxy)
-iptables
-Wiresharke (optional)

##Prerequisties
-Wifi Adapter(Moniter mode supported)
-Target device(your own phone or emulater)
-Burp Suite installed
